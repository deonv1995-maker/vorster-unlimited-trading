# Vorster Unlimited Trading v1 — Alpha 2

First phone-test build of the new application foundation.

Included:
- Branded splash screen and dashboard
- Manual products with phone image selection
- Saved colour tiles with swatches
- Manual customers
- Catalogue-style ordering
- Draft or confirmed order saving
- Status changes, sharing and Print / Save PDF
- Offline support
- Backup and restore

Data is stored locally on the phone. Export backups regularly.
